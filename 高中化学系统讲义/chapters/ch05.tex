\chapter{化学反应与电能}

第1章讨论了化学反应中的热量变化，本章讨论化学能与电能之间的相互转化。高一已经知道，原电池能把化学能转化为电能；本章先弄清原电池为什么能产生电流、怎样写电极反应式，再介绍各种实用的化学电源。反过来，用外加电源可以使不能自发进行的氧化还原反应发生，这就是电解，氯碱工业、电镀、精炼和冶炼活泼金属都以它为基础。最后用原电池原理分析金属的腐蚀，并用原电池和电解池的原理保护金属。贯穿全章的主线只有一条：氧化反应和还原反应在两个电极上分别进行，两极得失电子数相等。广东卷每年有两道左右的电化学选择题，实验题和工艺流程题中也常出现电镀和电解回收。

\section{原电池的工作原理}

\subsection{自发的氧化还原反应为什么能产生电流}
先回顾必修二：把锌片和铜片用导线连接后插入稀硫酸，电流计指针偏转，锌片溶解，铜片上产生气泡。锌是负极，铜是正极。这一节用锌与 \ce{CuSO4} 溶液的反应把这个过程看得更清楚。

把锌片直接插入 \ce{CuSO4} 溶液（图~\ref{fig:05-direct}(a)），锌片表面析出红色的铜，溶液温度升高：\ce{Zn + Cu^2+ = Zn^2+ + Cu}。这是一个自发的、放热的氧化还原反应。锌原子和 \ce{Cu^2+} 直接接触，电子在接触处直接转移，转移的方向杂乱无章，化学能主要以热的形式释放。

电流是电荷的定向移动。要得到电流，就得让电子沿导线定向移动，办法是把失电子的地方和得电子的地方分开。在图~\ref{fig:05-direct}(b) 中，用导线把锌片和铜片连接起来，电流计指针偏转。锌失电子的倾向比铜强得多（金属活动性 Zn$>$Cu），锌原子失去的电子留在锌片上，使锌片带有较多的负电荷，而铜片上的电子可以被溶液中的 \ce{Cu^2+} 夺走。于是，电子就像水从高处流向低处那样，自发地从锌片经导线流向铜片，在铜片表面被 \ce{Cu^2+} 接受。推动电子定向流动的，正是这个自发的氧化还原反应；反应释放的化学能有一部分不再变成热，而是变成了电能。在给定条件下不能自发进行的反应不能按这个方向设计成原电池，要使它发生必须外加电源（5.3 节）。

\subsection{双液原电池与盐桥}
把氧化剂和还原剂彻底分开，就得到图~\ref{fig:05-zncu} 的双液原电池：锌片插入 \ce{ZnSO4} 溶液，铜片插入 \ce{CuSO4} 溶液，两个烧杯用盐桥连接。盐桥是装有含 KCl 饱和溶液的琼胶的 U 形管，离子可以在其中移动。

读这张图要分两条路线。外电路：电子由负极锌片经导线、电流计流向正极铜片，电流方向与电子流向相反。内电路：负极区不断生成 \ce{Zn^2+}，正极区的 \ce{Cu^2+} 不断被消耗。如果没有盐桥，\ce{ZnSO4} 溶液中阳离子会越来越多而带正电，\ce{CuSO4} 溶液中 \ce{SO4^2-} 相对过剩而带负电，正电荷会吸引电子、负电荷会排斥电子，电子很快就流不动了。有了盐桥，\ce{Cl-} 移向负极区、\ce{K+} 移向正极区，两边溶液都保持电中性，电路构成通路，反应得以持续。因为 \ce{Cu^2+} 不再与锌直接接触，电流稳定，化学能转化为电能的效率也高。用只允许某些离子通过的离子交换膜代替盐桥，道理相同。

\begin{gainian}[原电池]
把化学能转化为电能的装置叫做\textbf{原电池}。电子流出、发生氧化反应的电极是\textbf{负极}；电子流入、发生还原反应的电极是\textbf{正极}。构成原电池需要：一个能自发进行的氧化还原反应，两个电极，电解质溶液（或熔融电解质），以及形成闭合回路。工作时，外电路中电子由负极流向正极；内电路中阳离子移向正极，阴离子移向负极。
\end{gainian}

\begin{yicuo}
电子只在导线和电极中移动，不进入溶液；溶液中靠离子的定向移动导电。负极也不一定是“更活泼的金属”，要看哪一极与电解质溶液自发反应：Mg、Al 插入 NaOH 溶液，只有 Al 与 NaOH 反应，Al 作负极；Fe、Cu 插入浓硝酸，Fe 钝化，Cu 作负极。
\end{yicuo}

\subsection{电极反应式的书写}
写电极反应式可以按四步进行。第一步，确定两极的反应物：负极是还原剂（或负极材料）失电子，正极是氧化剂得电子，由化合价变化找出各自的产物和转移的电子数。第二步，写出“反应物 $\pm\,n\,e^-$ $=$ 产物”的骨架。第三步，按介质补粒子使电荷守恒：酸性溶液用 \ce{H+}，碱性溶液用 \ce{OH-}，熔融碳酸盐用 \ce{CO3^2-}，能传导 \ce{O^2-} 的固体氧化物用 \ce{O^2-}，再用 \ce{H2O} 配平 H、O 原子。产物要能在该介质中存在：碱性溶液中不能保留 \ce{H+}；若碱足量并与产物充分反应，碳的最终氧化产物应写为 \ce{CO3^2-}，不保留 \ce{CO2}；酸性溶液中不能出现 \ce{OH-}。第四步检查：两极反应式（电子数相同）相加应等于总反应。

\begin{liti}[基础]
写出下列原电池的电极反应式和总反应：(1) Zn、Cu 用导线连接插入稀硫酸；(2) Mg、Al 用导线连接插入 NaOH 溶液；(3) Fe、石墨用导线连接插入 NaCl 溶液（溶液与空气接触）。
\tcblower
\jie (1) 负极：\ce{Zn - 2e- = Zn^2+}；正极：\ce{2H+ + 2e- = H2 ^}；总反应 \ce{Zn + 2H+ = Zn^2+ + H2 ^}。\\
(2) 自发反应是 \ce{2Al + 2NaOH + 6H2O = 2Na[Al(OH)4] + 3H2 ^}，Al 失电子，作负极。负极：\ce{Al - 3e- + 4OH- = [Al(OH)4]-}；正极：\ce{2H2O + 2e- = H2 ^ + 2OH-}。\\
(3) NaCl 溶液呈中性，在与空气接触的通常条件下，主要是溶解的 \ce{O2} 得电子，不按铁与酸生成氢气来处理。负极：\ce{Fe - 2e- = Fe^2+}；正极：\ce{O2 + 4e- + 2H2O = 4OH-}；总反应 \ce{2Fe + O2 + 2H2O = 2Fe(OH)2}。这正是 5.5 节铁生锈的原理。
\end{liti}

\begin{liti}[典型]
写出下列燃料电池的电极反应式：(1) 甲醇—空气，质子交换膜（酸性）；(2) 肼（\ce{N2H4}）—空气，KOH 溶液；(3) CO—空气，熔融 \ce{K2CO3}（正极通入空气和 \ce{CO2}）；(4) \ce{CH4}—空气，能传导 \ce{O^2-} 的固体氧化物电解质。
\tcblower
\silu 正极都是 \ce{O2} 得电子，产物只由介质决定，先写正极；再用“总反应 $-$ 正极反应”得负极。\\
\jie (1) 正：\ce{O2 + 4e- + 4H+ = 2H2O}；负：\ce{CH3OH - 6e- + H2O = CO2 ^ + 6H+}。\\
(2) 正：\ce{O2 + 4e- + 2H2O = 4OH-}；负：\ce{N2H4 - 4e- + 4OH- = N2 ^ + 4H2O}（总反应 \ce{N2H4 + O2 = N2 + 2H2O}）。\\
(3) 正：\ce{O2 + 4e- + 2CO2 = 2CO3^2-}；负：\ce{CO - 2e- + CO3^2- = 2CO2}。负极生成的 \ce{CO2} 可以循环到正极使用。\\
(4) 正：\ce{O2 + 4e- = 2O^2-}；负：\ce{CH4 - 8e- + 4O^2- = CO2 + 2H2O}。
\end{liti}

原电池原理还有几个应用：加快反应速率（锌与稀硫酸反应时滴入少量 \ce{CuSO4} 溶液，置换出的 Cu 与 Zn 构成原电池）；比较金属活动性（一般作负极的金属更活泼）；设计原电池（选一个自发的氧化还原反应，还原剂作负极或在负极反应，含氧化剂的溶液作正极区电解质）。

\section{化学电源}
实用的化学电源分三类：只能放电一次的\textbf{一次电池}（如碱性锌锰电池）；放电后可以充电、反复使用的\textbf{二次电池}（如铅酸蓄电池、锂离子电池）；以及把燃料和氧化剂不断从外部通入的\textbf{燃料电池}。

\subsection{燃料电池}
燃料电池的燃料（\ce{H2}、\ce{CH4}、\ce{CH3OH}、\ce{N2H4} 等）是还原剂，总在负极失电子；\ce{O2} 是氧化剂，总在正极得电子。图~\ref{fig:05-fuel} 是质子交换膜氢氧燃料电池的结构示意。两个电极都是多孔的、含催化剂的电极，\ce{H2} 通入负极一侧，在催化剂作用下失电子变成 \ce{H+}；电子经外电路流到正极，\ce{H+} 穿过质子交换膜到达正极，与 \ce{O2} 和电子结合成水。在高中题采用的理想模型中，膜只传导 \ce{H+}，既构成内电路，又把 \ce{H2} 和 \ce{O2} 隔开。

正极反应只取决于介质：酸性 \ce{O2 + 4e- + 4H+ = 2H2O}；碱性或中性 \ce{O2 + 4e- + 2H2O = 4OH-}；熔融碳酸盐 \ce{O2 + 4e- + 2CO2 = 2CO3^2-}；固体氧化物 \ce{O2 + 4e- = 2O^2-}。写出正极反应后，用总反应减去它，就得到负极反应，不容易出错。燃料电池使燃料的化学能直接转化为电能，通常有较高的能量转化效率；产物是否污染环境还取决于燃料种类，例如含碳燃料仍可能生成 \ce{CO2}。

\subsection{二次电池}
二次电池放电时是原电池，充电时是电解池（5.3 节），充电反应是放电反应的逆反应。图~\ref{fig:05-li} 是锂离子电池放电时的示意：负极是嵌有锂的石墨（\ce{Li_xC6}），正极是 \ce{Li_{1-$x$}CoO2}，电解质是能传导 \ce{Li+} 的有机溶液。放电时嵌锂石墨失去电子并释放 \ce{Li+}，\ce{Li+} 穿过隔膜嵌入正极的层状结构，电子经外电路到达正极；充电时 \ce{Li+} 又回到石墨层间。\ce{Li+} 在两极之间来回移动，所以这种电池又叫“摇椅电池”。

充电时，电池的负极接外电源的负极（作阴极），正极接外电源的正极（作阳极），即“负接负、正接正”。充电时阴极反应是放电负极反应的逆反应，阳极反应是放电正极反应的逆反应。

遇到陌生的新型电池，可按以下思路分析：先由元素化合价的变化（或题给的“放电时某物质减少”）确定正、负极；再定电子和离子的移动方向，注意放电时阳离子移向正极，充电时阳离子移向阴极；然后结合介质和膜允许通过的离子写电极反应；涉及计算时用电子守恒，1 mol 电子的电量约为 96500 C，相当于 26.8 A·h。

读图时，从电源出发沿电子的路线走一圈：电子从电源负极流出，经导线进入阴极，被移动到阴极表面的 \ce{Cu^2+} 接受；在阳极，\ce{Cl-} 失去电子，电子经导线流回电源正极。溶液中 \ce{Cu^2+} 向阴极移动，\ce{Cl-} 向阳极移动，离子的定向移动构成内电路。总反应为
\[\ce{CuCl2 ->[\text{电解}] Cu + Cl2 ^}\]
它是 \ce{Cu + Cl2 = CuCl2} 的逆反应，不能自发进行。外加电源像一台“电子泵”，从阳极抽走电子、向阴极压入电子，强制这个反应发生，电能转化为化学能。

\begin{gainian}[电解与电解池]
使电流通过电解质溶液（或熔融电解质）而在两个电极上分别发生氧化反应和还原反应的过程叫做\textbf{电解}，把电能转化为化学能的装置叫做\textbf{电解池}。与电源负极相连的电极是\textbf{阴极}，得电子，发生还原反应；与电源正极相连的电极是\textbf{阳极}，失电子，发生氧化反应。溶液中阳离子移向阴极，阴离子移向阳极。
\end{gainian}

\subsection{放电顺序及其依据}
\ce{CuCl2} 溶液中除了 \ce{Cu^2+}、\ce{Cl-}，还有水电离出的 \ce{H+} 和 \ce{OH-}。为什么阴极上是 \ce{Cu^2+} 而不是 \ce{H+} 得电子，阳极上是 \ce{Cl-} 而不是 \ce{OH-} 失电子？离子在电极上得到或失去电子叫做\textbf{放电}。同一电极上可能有多种反应竞争。通常可先从氧化性、还原性判断倾向，再结合离子浓度、pH 和电极材料确认；题给实验现象或产物优先，不能把经验顺序看成无条件的规则。

金属阳离子得电子生成金属的倾向与金属活动性顺序大致相反。例如 \ce{Fe + Cu^2+ = Fe^2+ + Cu} 说明通常更容易析出 Cu，而不是 Fe；\ce{2Fe^3+ + Cu = 2Fe^2+ + Cu^2+} 则说明 \ce{Fe^3+} 可优先得电子生成 \ce{Fe^2+}，不要把所有阳离子的放电都理解为“析出金属”。高中常见题可先抓住三类情况：
\begin{itemize}
\item \ce{Ag+}、\ce{Cu^2+} 在通常浓度下容易得电子析出金属；\ce{Fe^3+} 得电子先变为 \ce{Fe^2+}。
\item \ce{K+}、\ce{Ca^2+}、\ce{Na+}、\ce{Mg^2+}、\ce{Al^3+} 在通常水溶液电解中不析出对应金属，先发生水或 \ce{H+} 的还原，得到 \ce{H2}。
\item \ce{Zn^2+}、\ce{Fe^2+} 等与析氢反应的竞争受酸度、浓度和电极材料影响较大，不能只把一个“\ce{H+}”固定插在金属顺序表中。题目给出酸度、电镀条件或产物时，应按这些条件分析。
\end{itemize}

阳极首先看材料。铜、锌等活性阳极通常自身失电子溶解；石墨、铂等在高中常见题中按惰性阳极处理。惰性阳极上，常见卤离子的失电子倾向为 \ce{I-}>\ce{Br-}>\ce{Cl-}；较浓氯化物溶液常生成 \ce{Cl2}，\ce{SO4^2-}、\ce{NO3-} 等通常不放电而由水（或 \ce{OH-}）失电子生成 \ce{O2}。浓度变化或特殊电极可改变竞争结果，遇到稀氯化物溶液尤其不能无条件断言只放 \ce{Cl2}。金属阳极还可能钝化，故“只要是金属就一定溶解”同样不准确。

\end{enumerate}

\jie (1) \ce{Cl-} 全部放电需 0.1 mol 电子，\ce{Cu^2+} 全部放电需 0.2 mol 电子。第一阶段（0～0.1 mol 电子）：阴极析出 Cu，阳极放出 \ce{Cl2}，相当于电解 \ce{CuCl2}；第二阶段（0.1～0.2 mol）：阴极析出 Cu，阳极放出 \ce{O2}，相当于电解 \ce{CuSO4}，生成 \ce{H2SO4}；第三阶段（0.2 mol 以后）：阴极放出 \ce{H2}，阳极放出 \ce{O2}，相当于电解水。\\

\end{liti}

\subsection{电镀、电解精炼与电冶金}
电镀是利用电解在某些金属表面镀上一薄层其他金属或合金。在铁件上镀铜时（图~\ref{fig:05-plate}(a)），镀层金属铜作阳极，镀件作阴极，含 \ce{Cu^2+} 的溶液作电镀液：阳极 \ce{Cu - 2e- = Cu^2+}，阴极 \ce{Cu^2+ + 2e- = Cu}。阳极溶解多少铜，阴极就析出多少铜，电镀液的浓度基本不变。

电解精炼铜（图~\ref{fig:05-plate}(b)）的装置与电镀相似：粗铜作阳极，纯铜作阴极，\ce{CuSO4} 溶液（加少量硫酸）作电解液。粗铜中比铜活泼的 Zn、Fe、Ni 等也失电子进入溶液，但它们的离子氧化性比 \ce{Cu^2+} 弱，不在阴极析出；不如铜活泼的 Ag、Au 等不失电子，随着阳极溶解沉积在槽底，形成阳极泥（可从中回收贵金属）。所以阴极只析出铜，而阳极减少的质量不等于阴极增加的质量，溶液中 $c(\ce{Cu^2+})$ 略有减小。

\subsection{电化学计算}
电化学计算的依据是电子守恒：串联电路中各电极转移的电子数相等。对常见的析气、析出金属反应，有 $4e^-\sim\ce{O2}\sim2\ce{H2}\sim2\ce{Cl2}\sim2\ce{Cu}\sim4\ce{Ag}$；这些是各自电极反应的计量关系，不表示它们总在同一电池中出现。\ce{H+}、\ce{OH-} 的量必须按具体电极反应及膜迁移另算。若已知电流和时间，电量 $Q=It$，$n(e^-)=\dfrac{Q}{F}$，法拉第常数 $F=96500$ C·mol$^{-1}$。

\begin{liti}[典型]
用惰性电极电解 500 mL \ce{CuSO4} 溶液，通电一段时间后阴极增重 0.64 g（无气体产生），设溶液体积不变。(1) 阳极产生气体的体积（标准状况）为多少？(2) 电解后溶液的 $c(\ce{H+})$ 为多少？(3) 若用 0.5 A 的恒定电流，需通电多少秒？
\tcblower
\jie (1) $n(\ce{Cu})=0.01$ mol，转移 0.02 mol 电子；阳极 \ce{2H2O - 4e- = O2 ^ + 4H+}，$n(\ce{O2})=0.005$ mol，$V=0.112$ L。(2) 生成 \ce{H+} 0.02 mol，$c(\ce{H+})=0.04$ mol·L$^{-1}$。(3) $t=\dfrac{n(e^-)\cdot F}{I}=\dfrac{0.02\times96500}{0.5}=3860$ s。
\end{liti}

\section{金属的腐蚀与防护}

\subsection{金属的电化学腐蚀}
金属与接触到的物质直接发生氧化还原反应而被腐蚀，叫做化学腐蚀，如铁在高温下与氯气反应。生活中更普遍、危害更大的是\textbf{电化学腐蚀}：不纯的金属与电解质溶液接触，形成原电池，较活泼的金属被氧化。钢铁中含有少量碳，潮湿空气中钢铁表面会形成一层溶有 \ce{O2}、\ce{CO2} 等的水膜，铁、碳和水膜就构成了无数微小的原电池，铁作负极。

水膜呈中性或弱酸性时（最常见），正极上溶解的 \ce{O2} 得电子，叫做\textbf{吸氧腐蚀}。图~\ref{fig:05-rust} 是铁板上一滴食盐水中发生吸氧腐蚀的示意：液滴边缘与空气接触，\ce{O2} 容易溶入，是正极区；液滴中心 \ce{O2} 难以到达，铁失电子溶解，是负极区。电子在铁板内部由中心流向边缘，\ce{Fe^2+} 与 \ce{OH-} 在两区之间相遇生成 \ce{Fe(OH)2}，进一步被氧化，最终在液滴边缘内侧形成一圈铁锈。

\textbf{牺牲阳极法}利用原电池原理：在钢铁外壳上连接比铁活泼的锌块或镁块，锌作负极被氧化，钢铁作正极，只得电子而被保护。锌块会逐渐消耗，需要定期更换。（这里的“阳极”沿用了习惯名称，指发生氧化反应的电极。）\textbf{外加电流法}利用电解原理：被保护的金属接直流电源的负极作阴极，另用惰性材料作辅助阳极接电源正极。在相近环境中，使钢铁作原电池负极或接外电源正极，通常会加快腐蚀；使其作正极或阴极则可得到保护。具体腐蚀速率还受酸度、含氧量、温度和保护层影响，不把不同条件下的腐蚀机械排成绝对顺序。
