\chapter{元素化合物与化工流程}

本章把必修的元素化学和高三的工艺流程题放在一起讲。高一学过的 Na、Al、Fe、Cu、Cl、S、N、Si 等元素的物质，数量多、方程式多，单靠记忆容易混乱；如果按“化合价”和“物质类别”两条线索把它们排进一张坐标图（价类二维图），每个转化就有了位置和理由。化工流程题以这些转化为基础，再用上前面各章的反应原理（速率、平衡、$K_\text{sp}$、电化学）和实验方法（分离提纯），解决“从原料怎样得到产品”的实际问题。广东卷选择题考过价类二维图（2024年第14题、2026年第13题）、物质转化（2025年第7题）和陈述因果（2025年第8题）；第18题是 14 分的工艺流程题，三年分别是从炭渣中提镓（2024）、从多金属精矿提取 Fe、Cu、Ni（2025）、从金精矿提金（2026），综合考查预处理、陌生方程式、$K_\text{sp}$ 计算、配合物与晶胞。本章先用价类二维图整理元素化合物，再讲流程图的读法和各操作的作用，然后讲流程中的方程式书写与调 pH 计算，最后完整分析 2025年第18题。

\section{用价类二维图整理元素化合物}

\subsection{价类二维图怎样读}
价类二维图研究的是\textbf{同一种元素}组成的各种物质。高一学过两种给物质归类的办法：一是按组成分为单质、氧化物、酸、碱、盐；二是按元素的化合价，化合价改变的反应是氧化还原反应，化合价升高的物质是还原剂、需要氧化剂才能实现，化合价降低则需要还原剂。把这两种办法合在一张图上，横轴是物质类别，纵轴是化合价，每种物质就是图上的一个点，每个转化就是一个箭头。可以把它看成一张“地图”：沿水平方向走，换的是物质类别；沿竖直或斜向走，换的是价态。

\begin{gainian}[价类二维图的读法]
(1) 水平箭头：化合价不变，是非氧化还原反应，靠酸、碱、盐、水之间的反应实现（如酸性氧化物与水化合、碱与酸中和、盐与碱复分解）。\\
(2) 竖直或斜向箭头：化合价改变，是氧化还原反应。向上需要氧化剂（\ce{O2}、\ce{Cl2}、\ce{H2O2}、\ce{HNO3} 等），向下需要还原剂（\ce{H2}、CO、C、Fe、\ce{SO2} 等）。\\
(3) 最高价只有氧化性，最低价只有还原性，中间价态既有氧化性又有还原性。\\
(4) 同一元素的两种价态相遇时，化合价“只靠拢、不交叉”；相邻价态之间不发生氧化还原反应（如 \ce{SO2} 可用浓硫酸干燥）。
\end{gainian}

读这张图时，先看水平箭头。$+3$ 价一行中，\ce{Fe(OH)3} 与酸反应得到 \ce{Fe^3+} 盐，\ce{Fe^3+} 盐与碱反应得到 \ce{Fe(OH)3}（⑥），\ce{Fe(OH)3} 受热分解为 \ce{Fe2O3}（⑦），都不涉及价态变化；$+2$ 价一行的 \ce{Fe^2+} 盐与碱反应生成 \ce{Fe(OH)2}（④）也是如此。再看竖直和斜向箭头，它们都是氧化还原反应：
\begin{itemize}
\item 向上（需要氧化剂）：①\ce{Fe + 2H+ = Fe^2+ + H2 ^}，弱氧化剂只把铁氧化到 $+2$ 价；②\ce{2Fe + 3Cl2 ->[\text{点燃}] 2FeCl3}，强氧化剂把铁直接氧化到 $+3$ 价；③\ce{2Fe^2+ + Cl2 = 2Fe^3+ + 2Cl-}，\ce{2Fe^2+ + H2O2 + 2H+ = 2Fe^3+ + 2H2O}；⑤\ce{4Fe(OH)2 + O2 + 2H2O = 4Fe(OH)3}，现象是白色沉淀迅速变为灰绿色，最后变为红褐色；⑨\ce{3Fe + 2O2 ->[\text{点燃}] Fe3O4}，\ce{3Fe + 4H2O(g) ->[\text{高温}] Fe3O4 + 4H2}。
\item 向下（需要还原剂）：③的反方向 \ce{2Fe^3+ + Fe = 3Fe^2+}，\ce{2Fe^3+ + Cu = 2Fe^2+ + Cu^2+}（腐蚀铜电路板）；⑧\ce{Fe2O3 + 3CO ->[\text{高温}] 2Fe + 3CO2}（高炉炼铁）。
\end{itemize}
$+2$ 价处于中间价态，所以 \ce{Fe^2+} 既能被氧化又能被还原，而且容易被空气中的 \ce{O2} 氧化，这就是 \ce{FeSO4} 溶液要加少量铁粉保存、制 \ce{Fe(OH)2} 要隔绝空气的原因。两种离子的检验也要记住：\ce{Fe^3+} 遇 KSCN 溶液变红；\ce{Fe^2+} 与 \ce{K3[Fe(CN)6]} 溶液生成蓝色沉淀。

\tcblower
\silu 先判断箭头是向上还是向下，再选试剂；除杂时要求不引入新杂质。\\
\jie (1) 由 $+2$ 价到 $+3$ 价的转化（③向上、⑤）需要氧化剂。(2) 加入过量铁粉后过滤：\ce{2Fe^3+ + Fe = 3Fe^2+}；通入适量 \ce{Cl2}：\ce{2Fe^2+ + Cl2 = 2Fe^3+ + 2Cl-}（产物只有 \ce{FeCl3}，不引入杂质）。(3) \ce{Fe(OH)2} 处于中间价态，很容易被 \ce{O2} 氧化；煮沸除去溶解的 \ce{O2}，液面下挤出避免 NaOH 溶液滴落时带入空气。
\end{liti}

\textbf{氮。}向上的主线是 \ce{N2 -> NO -> NO2 -> HNO3}：②\ce{N2 + O2 ->[\text{放电}] 2NO}（雷电固氮），③\ce{2NO + O2 = 2NO2}，④\ce{3NO2 + H2O = 2HNO3 + NO}（\ce{NO2} 中氮从 $+4$ 价一部分升到 $+5$、一部分降到 $+2$，是歧化反应）。工业制硝酸则从氨出发：①\ce{N2 + 3H2 <=>[\text{高温、高压}][\text{催化剂}] 2NH3}，⑦\ce{4NH3 + 5O2 ->[\text{催化剂}][\text{△}] 4NO + 6H2O}，再走③④。向下的支线是硝酸作氧化剂：⑤\ce{Cu + 4HNO3}（浓）\ce{= Cu(NO3)2 + 2NO2 ^ + 2H2O}，⑥\ce{3Cu + 8HNO3}（稀）\ce{= 3Cu(NO3)2 + 2NO ^ + 4H2O}；硝酸见光易分解（\ce{4HNO3 ->[\text{光照}] 4NO2 ^ + O2 ^ + 2H2O}），所以保存在棕色瓶中。$-3$ 价一行是水平转化⑨：\ce{NH3 + HCl = NH4Cl}（白烟）；铵盐与碱共热放出氨，\ce{2NH4Cl + Ca(OH)2 ->[\text{△}] CaCl2 + 2NH3 ^ + 2H2O} 是实验室制氨的反应，氨能使湿润的红色石蕊试纸变蓝。

\textbf{硫。}向上的主线是 \ce{H2S -> S -> SO2 -> SO3 -> H2SO4}，工业制硫酸走的就是后三步：②\ce{S + O2 ->[\text{点燃}] SO2}，③\ce{2SO2 + O2 <=>[\text{催化剂}][\text{△}] 2SO3}，④\ce{SO3 + H2O = H2SO4}。$+4$ 价一行是 \ce{SO2} 作为酸性氧化物的水平转化（⑤\ce{SO2 + H2O <=> H2SO3}，⑦与碱生成亚硫酸盐）；$+4$ 价处于中间价态，亚硫酸及其盐容易被空气氧化（⑥⑧），\ce{SO2} 还能使溴水、酸性 \ce{KMnO4} 溶液褪色（还原性）。\ce{SO2} 与 \ce{H2S} 相遇生成 S：\ce{SO2 + 2H2S = 3S + 2H2O}，$+4$ 价和 $-2$ 价向中间的 0 价靠拢，这时 \ce{SO2} 表现氧化性。向下的支线⑨是浓硫酸的强氧化性：\ce{Cu + 2H2SO4}（浓）\ce{->[\text{△}] CuSO4 + SO2 ^ + 2H2O}，浓硫酸还能在常温下使 Fe、Al 钝化。浓硫酸的吸水性（作干燥剂）、脱水性（使蔗糖变黑）不改变硫的价态。注意 \ce{SO2} 的漂白性是与有色物质化合成不稳定的无色物质，加热又恢复原色，它也不能漂白酸碱指示剂，所以 \ce{SO2} 使紫色石蕊溶液只变红、不褪色。

\end{liti}

\subsection{钠、铝、铜、氯、硅的重要转化}
其余几种元素也可以放进价类二维图来理解，只是转化集中在少数几条线上。钠在化合物中只有 $+1$ 价，除了 Na 与水、与 \ce{O2} 的反应，其余转化都在 $+1$ 价这一水平线上（\ce{Na2O2} 中氧为 $-1$ 价，它与水、\ce{CO2} 的反应是氧的歧化）。铝只有 0 和 $+3$ 价，$+3$ 价一行的 \ce{Al2O3}、\ce{Al(OH)3} 既能与酸又能与强碱反应（两性），流程题中常用这一点把铝与其他金属分开。铜有 0、$+1$、$+2$ 价，常考 Cu 被氧化为 \ce{Cu^2+}。氯的价态最多（$-1$、0、$+1$、$+4$、$+5$、$+7$），含氯消毒剂（\ce{Cl2}、\ce{ClO-}、\ce{ClO2}）都利用氯的正价或 0 价的氧化性，$-1$ 价的 HCl 没有这种性质。硅的转化几乎都在 $+4$ 价一行：\ce{SiO2} 是酸性氧化物，但不溶于水，在流程中“酸浸”时留在滤渣里，“碱浸”时则溶解为 \ce{SiO3^2-}。重要反应见表~\ref{tab:13-elem}。

能满足下列物质间直接转化关系，且推理成立的是\\
\centerline{单质 X $\xrightarrow{\ce{O2}}$ 氧化物1 $\xrightarrow{\ce{O2}}$ 氧化物2 $\xrightarrow{\ce{H2O}}$ 酸（或碱）$\xrightarrow{\text{NaOH（或 HCl）}}$ 盐}
\xxb{X 可为铝，盐的水溶液一定显酸性}{X 可为硫，氧化物1可使品红溶液褪色}{X 可为钠，氧化物2可与水反应生成 \ce{H2}}{X 可为碳，盐的热稳定性：\ce{NaHCO3}$>$\ce{Na2CO3}}

\textbf{解析：}这条转化链在价类二维图上是“单质$\to$低价氧化物$\to$高价氧化物”两次向上，再沿水平线走到酸（碱）和盐。A：\ce{Al2O3} 不能再被 \ce{O2} 氧化，也不与水反应，错；B：\ce{S -> SO2 -> SO3 -> H2SO4 -> Na2SO4}，\ce{SO2} 能使品红褪色，对；C：\ce{Na2O2} 与水反应生成 \ce{O2}，错；D：\ce{Na2CO3} 比 \ce{NaHCO3} 稳定，错。答案：B。
\end{zhenti}

图中粗箭头是主线，目标元素一直沿着它走；方框上方的细箭头是加入的试剂和条件，下方的细箭头是分出去的物质（尾气、滤渣、母液），它们或者是要除去的杂质，或者是副产品；虚线是循环物质，即在后面的步骤中生成（或剩余）、又能回到前面作为试剂的物质。读一道新流程题，可以按下面的顺序：
\begin{enumerate}
\item 读题头，写出原料的主要成分和目标产品，分清哪种元素是目标、哪些是杂质。
\item 沿主线逐个方框看“进”和“出”：加了什么、在什么条件下、得到了什么、分出了什么。分出的固体叫“滤渣”或“浸出渣”，溶液叫“滤液”，要判断目标元素此时在固体中还是在溶液中。

\item 找循环物质：某物质既出现在前面某步的“进”中，又出现在后面某步的“出”中。
\end{enumerate}
流程题的各小问相对独立，一处看不懂，不妨碍做其他小问。

\subsection{各操作的作用与答题依据}
回答“某步操作的目的”时，依据只有三类：反应速率（第2章）、化学平衡与溶解平衡（第3、4章）、物质的性质（本章第一节）。下面按流程顺序逐一说明。

\textbf{粉碎（研磨）}增大了固体与气体或溶液的接触面积，使反应速率加快，反应也更充分，所以答“增大接触面积，加快反应速率，提高浸出率”。\textbf{焙烧（煅烧）}是在高温下让固体与空气或其他试剂反应，常见目的有：把硫化物氧化为氧化物（\ce{4FeS2 + 11O2 ->[\text{高温}] 2Fe2O3 + 8SO2}，同时产生的 \ce{SO2} 要处理或用来制硫酸）；除去碳和有机物；与纯碱等共同焙烧，把难溶矿物转化为可溶的盐（如铬铁矿转化为 \ce{Na2CrO4}）。

\textbf{浸出}是用水、酸或碱溶液把固体中的可溶成分溶出。酸浸使金属氧化物溶解为金属离子（\ce{Fe2O3 + 6H+ = 2Fe^3+ + 3H2O}），\ce{SiO2} 等不溶物进入浸出渣；碱浸则可溶解 Al、\ce{Al2O3}、\ce{SiO2}，与不溶于碱的铁、铜等分开。要区分两种设问：提高浸出\emph{速率}的措施是粉碎、搅拌、适当升温、适当增大酸（碱）的浓度；提高浸出\emph{率}还可以延长浸出时间、多次浸取。“适当”二字有依据：温度过高，盐酸、氨会挥发，\ce{H2O2}、\ce{NH4HCO3} 会分解；酸过量太多，后面调 pH 时要消耗更多的碱。

\textbf{除杂}常分两步。先用氧化剂（或还原剂）调整杂质的价态，最典型的是把 \ce{Fe^2+} 氧化为 \ce{Fe^3+}，因为 \ce{Fe^3+} 在 pH 较低时就能沉淀完全；氧化剂常用 \ce{H2O2}（还原产物是水，不引入杂质，但温度不能太高）、\ce{O2} 或与产品同元素的物质（如 \ce{MnO2} 用于制锰盐）。然后调 pH，使杂质离子沉淀完全而目标离子不沉淀；调 pH 的试剂要能消耗 \ce{H+}，又不引入新杂质，如含 \ce{Cu^2+} 的溶液用 CuO、\ce{Cu(OH)2} 或 \ce{Cu2(OH)2CO3}。pH 的范围怎样计算，见第~\ref{sec:13-ksp} 小节。

\textbf{萃取与反萃取}用于分离性质相近的金属离子。有机萃取剂（记作 HR）与某种金属离子结合成能溶于有机溶剂的化合物，存在平衡
\[\ce{M^2+(aq) + 2HR(org) <=> MR2(org) + 2H+(aq)}\]
其中 aq 表示水相，org 表示有机相。水相酸度较低时平衡正向移动，M 进入有机相，与留在水相中的杂质分开（萃取）；分液后向有机相中加入较浓的酸，平衡逆向移动，M 又回到水相（反萃取），得到较纯、较浓的溶液，萃取剂再生后循环使用（图~\ref{fig:13-ext}）。题目问“为什么某离子易进入有机相”，从配位作用和配合物的疏水性回答；问“反萃取加什么”，从平衡移动回答。

\textbf{结晶方式}由溶解度随温度的变化决定（图~\ref{fig:13-sol}）。溶解度受温度影响小的物质（如 NaCl）用蒸发结晶；溶解度随温度升高明显增大的物质（如 \ce{KNO3}），以及带结晶水的物质（如 \ce{CuSO4.5H2O}、\ce{FeSO4.7H2O}，蒸干会失去结晶水），用“蒸发浓缩、冷却结晶、过滤”。要在高温下除去溶解度小的杂质或析出溶解度随温度升高而减小的产品（如 \ce{Li2CO3}），用“趁热过滤”。易水解的盐（如由 \ce{MgCl2.6H2O} 制无水 \ce{MgCl2}）要在 HCl 气流中加热，以抑制水解（第4章）。

\tcblower
\silu 先确定目标元素是铁，产品是 $+2$ 价的 \ce{FeSO4}；原料中有 $+3$ 价铁，所以流程中必须有还原步骤。\\
\jie (1) 增大接触面积，加快酸浸速率，提高浸出率；\ce{Fe2O3 + 6H+ = 2Fe^3+ + 3H2O}。(2) 滤渣1是不溶于稀硫酸的 \ce{SiO2}；滤渣2是剩余的铁粉。(3) 把 \ce{Fe^3+} 还原为 \ce{Fe^2+}：\ce{2Fe^3+ + Fe = 3Fe^2+}（同时消耗多余的酸）；取少量溶液，滴加 KSCN 溶液，不变红说明 \ce{Fe^3+} 已除尽。(4) 绿矾含结晶水，蒸干会失去结晶水，\ce{Fe^2+} 在加热时也更易被氧化，所以用蒸发浓缩、冷却结晶；用冰水洗涤，以减少晶体的溶解损失。

\section{流程中的方程式与计算}

\subsection{陌生氧化还原（离子）方程式的书写}
流程题中的方程式多数没有在课本上出现过，但都必须满足三个守恒：氧化剂得到的电子数等于还原剂失去的电子数（电子守恒），离子方程式两边电荷相等（电荷守恒），各元素原子数相等（原子守恒）。按这个顺序依次配平，就是下面的四步法。
\begin{enumerate}
\item \textbf{定物质}：根据题给信息和价态规律，写出氧化剂、还原剂、氧化产物、还原产物。
\item \textbf{配电子}：标出变价元素的化合价，按得失电子的最小公倍数确定这四种物质的系数。
\item \textbf{配电荷}：看介质。酸性介质用 \ce{H+} 配平电荷，碱性介质用 \ce{OH-}；中性介质一般在左边补 \ce{H2O}，右边生成 \ce{H+} 或 \ce{OH-}。酸性条件下方程式中不能出现 \ce{OH-}，碱性条件下不能出现 \ce{H+}。
\item \textbf{配原子}：用 \ce{H2O} 配平 H、O，最后用 O 原子数检查。
\end{enumerate}

\subsection{\texorpdfstring{$K_\text{sp}$}{Ksp} 与调 pH 的计算}\label{sec:13-ksp}

\textbf{读流程。}原料含 Fe、Al、Cu、Ni 四种金属元素，目标是把 Fe 和 Cu、Ni 分别提取出来，Al 是要除去的杂质。沿图~\ref{fig:13-2025} 的主线追踪各元素：“酸浸”时金属溶解为离子，通入的 \ce{SO2} 是还原剂，把 \ce{Fe^3+} 还原为 \ce{Fe^2+}（\ce{2Fe^3+ + SO2 + 2H2O = 2Fe^2+ + SO4^2- + 4H+}），不溶物成为固体残渣；“高压加热”时铁以 \ce{Fe2O3} 形式分出，转入下方的冶铁支线；“沉铝”时铝以滤饼（\ce{Al(OH)3}）形式分出；“选择萃取”把 Cu、Ni 分别转入有机相，硫酸根留在水相。整个流程每一步只“卸下”一种元素，这是读懂它的关键。

(1) 依据是影响速率的因素：搅拌、粉碎精矿、适当提高酸浸温度或酸的浓度（任写一条）。

(2) 浸取液中铁以 \ce{Fe^2+} 存在。高压加热时，\ce{O2} 把 \ce{Fe^2+} 氧化为 $+3$ 价，并在高温下以 \ce{Fe2O3} 析出。按四步法：Fe 失 1 个电子，\ce{O2} 得 4 个电子，得 4 \ce{Fe^2+}、1 \ce{O2}、2 \ce{Fe2O3}；左边电荷 $+8$，酸性介质右边补 8 \ce{H+}；左边补 4 \ce{H2O}。
\[\ce{4Fe^2+ + O2 + 4H2O ->[\text{高压}][\text{△}] 2Fe2O3 v + 8H+}\]
为什么此时 \ce{Al^3+} 不沉淀？pH$=3.0$ 时 $c(\ce{OH-})=10^{-11}$ mol·L$^{-1}$，对 \ce{Al(OH)3}，只要 $c(\ce{Al^3+})<1.3$ mol·L$^{-1}$，就有 $Q=c(\ce{Al^3+})\times10^{-33}<K_\text{sp}$，不会沉淀；而 \ce{Fe(OH)3} 的 $K_\text{sp}$ 小得多，铁可以沉淀完全。

(3) “沉铝”要使 \ce{Al^3+} 沉淀，而 \ce{Cu^2+}、\ce{Ni^2+} 不沉淀，所以 pH 的上限由两者中较早开始沉淀的一种决定。\ce{Cu^2+} 开始沉淀：$c^2(\ce{OH-})=\dfrac{2.2\times10^{-20}}{0.022}=1.0\times10^{-18}$，$c(\ce{OH-})=10^{-9}$ mol·L$^{-1}$，pH$=5$；\ce{Ni^2+} 开始沉淀：$c^2(\ce{OH-})=\dfrac{5.5\times10^{-16}}{0.042}\approx1.3\times10^{-14}$，pH$\approx7.1$。\ce{Cu^2+} 先沉淀，pH 最高调至 5。此时 $c(\ce{Al^3+})=\dfrac{1.3\times10^{-33}}{(10^{-9})^3}=1.3\times10^{-6}$ mol·L$^{-1}<10^{-5}$ mol·L$^{-1}$，铝已沉淀完全，说明这个 pH 上限是合理的。答案：5。

\subsection*{二、方法提升}
做元素化合物题，先在价类二维图上给物质定位，再判断转化方向和所需试剂，比逐条回忆方程式可靠。做流程题，先写出原料成分和目标产品，再沿主线看每个方框加入了什么、分出了什么，判断目标元素此时的存在形式；回答“目的”类设问时，说出依据（速率、平衡或物质性质），而不是只写结论。

\subsection*{三、易错点归纳}
\begin{enumerate}
\item 酸性条件下的离子方程式中出现 \ce{OH-}，或碱性条件下出现 \ce{H+}。
\item 调 pH 时选用会引入杂质的试剂（如用 NaOH 调含 \ce{Cu^2+} 溶液的 pH 以制纯净的 \ce{CuSO4}）。
\item 混淆“开始沉淀”与“沉淀完全”所用的浓度：前者用原浓度，后者用 $1.0\times10^{-5}$ mol·L$^{-1}$。
\item 认为 \ce{SO2} 能使紫色石蕊溶液先变红后褪色（只变红不褪色）。
\item 认为 \ce{Na2O2} 是碱性氧化物；或认为 \ce{Na2O2} 与 \ce{CO2} 反应时 \ce{CO2} 是氧化剂（实际是 \ce{Na2O2} 自身歧化）。
\item 带结晶水的产品或受热易分解的产品用蒸发结晶（应蒸发浓缩、冷却结晶）。
\end{enumerate}

\zhangmo{练习解析}
\begin{jiexilist}
\item \ans{B}A：浓硝酸见光易分解，所以保存在棕色瓶中，与强氧化性无因果关系；B：浓硫酸使蔗糖脱水炭化，正确；C：两陈述均正确但无因果关系；D：两陈述均正确但无因果关系。
\item \ans{C}A：使品红褪色是漂白性，使 \ce{KMnO4} 褪色是还原性；B：\ce{H2SO3} 酸性弱于 HCl，不反应；C：\ce{SO2} 中 S 由 $+4$ 降为 0，体现氧化性，正确；D：\ce{SO2 + Cl2 + 2H2O = H2SO4 + 2HCl}，漂白性消失。
\item (1) \ce{2Fe^3+ + Cu = 2Fe^2+ + Cu^2+}；(2) \ce{[Al(OH)4]- + CO2 = Al(OH)3 v + HCO3-}；(3) \ce{2MnO4^- + 5H2O2 + 6H+ = 2Mn^2+ + 5O2 ^ + 8H2O}（Mn 得 5 个电子，\ce{H2O2} 中两个 O 共失 2 个电子，最小公倍数 10）。
\item 1.12；0.1；2.8。$n(\ce{Na2O2})=0.1$ mol；\ce{2Na2O2 + 2H2O = 4NaOH + O2 ^}，生成 0.05 mol \ce{O2}，每生成 1 mol \ce{O2} 转移 2 mol 电子，共 0.1 mol；\ce{2Na2O2 + 2CO2 = 2Na2CO3 + O2}，固体由 \ce{Na2O2} 变为 \ce{Na2CO3}，每摩尔增重相当于 1 mol “CO” 的质量：$0.1\times28=2.8$ g。
\item \ce{Fe^2+}；\ce{Cu^2+}；\ce{Fe^3+}。氧化性 \ce{Fe^3+}$>$\ce{Cu^2+}，铁先还原 \ce{Fe^3+}，再置换 \ce{Cu^2+}；有 Cu 析出说明 \ce{Fe^3+} 已反应完（Cu 也能与 \ce{Fe^3+} 反应），滤渣中无 Fe 说明 \ce{Cu^2+} 可能有剩余。
\item \ans{B}A：a 为 Mg，Mg 与盐酸生成 \ce{MgCl2} 是置换反应，不一定是化合反应；B：存在 $+2$ 价的碱 e 转化为 $+3$ 价的碱 d，只能是 Fe，\ce{FeO}（黑）$\to$\ce{Fe^2+}（浅绿）$\to$\ce{Fe(OH)2}（白）$\to$\ce{Fe(OH)3}（红褐），一定有颜色变化，正确；C：加热饱和 \ce{FeCl3} 溶液可能直接得到 \ce{Fe(OH)3} 沉淀，不一定是胶体；D：\ce{Fe2O3}、\ce{Fe(OH)3} 都能与盐酸反应生成 \ce{FeCl3}，Fe 位于 d 区。
\item (1) \ce{Ga^3+ + 4Cl- = [GaCl4]-}。(2) 铁；\ce{[FeCl4]-}。加铝片将 \ce{Fe^3+} 还原为 \ce{Fe^2+}（\ce{Fe^2+} 最多结合 2 个 \ce{Cl-}，不能形成带负电荷的配离子），避免铁随 \ce{[FeCl4]-} 进入Ⅱ室。(3) 高；NaCl（增大 $c(\ce{Cl-})$ 而不增大酸度，使 \ce{Ga^3+ + 4Cl- <=> [GaCl4]-} 正向移动）。(4) 3.2；$4.0\times10^{-7}$。由 $K_\text{a}=\dfrac{c(\ce{H+})c(\ce{F-})}{c(\ce{HF})}=10^{-3.2}$，$c(\ce{F-})>c(\ce{HF})$ 要求 $c(\ce{H+})<10^{-3.2}$ mol·L$^{-1}$，pH$>3.2$；$c(\ce{[AlF6]^3-})=\dfrac{K_\text{sp}}{c^3(\ce{Na+})}=\dfrac{4.0\times10^{-10}}{0.10^3}=4.0\times10^{-7}$ mol·L$^{-1}$。
\item 先控制 $c(\ce{H2O2})$ 为 $x_1$，与 HCl 溶液浸出 Ag 后过滤除去（Ag 进入溶液，Au 留在滤渣中）；再控制 $c(\ce{H2O2})$ 为 $x_3$，与 HCl 溶液浸出 Au（得到含 \ce{[AuCl4]-} 的滤液2）。这样既除去了银、提高了金的纯度，又使金基本完全浸出。
