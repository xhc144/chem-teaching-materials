# 高中化学教学资料

本仓库收录高中化学课件、思维导图、复习清单与高考试题，以及整合编写的《高中化学系统讲义》。

## 高中化学系统讲义

完整讲义共 **198 页**，采用墨经书籍模板的 A4 单栏排版，包含目录、例题、章末分层练习、综合训练及完整解析。面向学完高一、尚未学习高二化学的学生，覆盖三册选择性必修、必要的高一基础、实验与化工流程，为广东新高考化学 90 分目标打基础。

- [阅读或下载完整 PDF](高中化学系统讲义/高中化学系统讲义.pdf)
- [下载独立 LaTeX 源码](高中化学系统讲义/高中化学系统讲义.tex)

PDF 已实际编译，并完成全书图文、目录、符号和分页检查。详细文件说明、依赖和编译方法见 [讲义 README](高中化学系统讲义/README.md)。

## 编译与维护讲义

使用 XeLaTeX，建议安装 TeX Live 2025 完整版本，并按 [讲义 README](高中化学系统讲义/README.md) 安装宏包和字体。在仓库根目录执行：

```sh
cd 高中化学系统讲义
latexmk -xelatex -interaction=nonstopmode -halt-on-error 高中化学系统讲义.tex
```

单文件源码内嵌所需墨经模板文件，可独立编译；图示由 TikZ/chemfig 绘制，无需额外图片。分文件工程由 `main.tex`、`preamble.tex`、`book-config.tex`、`chapters/` 和墨经模板文件组成。修改分章正文后，在讲义目录运行 `python3 tools/assemble_source.py` 重新生成单文件源码，再编译 PDF；更新源码包时一并同步这些文件。
